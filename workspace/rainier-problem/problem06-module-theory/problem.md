# Normalized Math Problem

## LaTeX (Normalized)

Let $q$ be a prime power, let $V=\mathbb F_q^n$ with standard basis vector $e_1=(1,0,\ldots,0)$, and let $r$ be an integer with $1\leq r\leq \lfloor n/2\rfloor$. Empty products are interpreted as $1$. Determine the exact number of $\mathbb F_q$ linear endomorphisms $T:V\to V$ such that $T^2=0$, $\operatorname{rank}(T)=r$, and $T(e_1)\neq0$.

## Domain Explanation

This problem involves classifying square zero endomorphisms as modules over a truncated polynomial ring while tracking a marked vector outside the kernel, which are part of Abstract Algebra and Module theory.
The problem also involves finite vector spaces and Gaussian subspace counts, which are part of Linear Algebra.
However, those vector space counts only provide the finite coordinates for the module structure imposed by the square zero action and the marked vector constraint.
